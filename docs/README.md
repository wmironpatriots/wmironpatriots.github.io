# frc6423.org

Official website for **FRC Team 6423**.

Built with **Astro**.

## Getting Started

```bash
git clone https://github.com/wmironpatriots/wmironpatriots.github.io.git
cd wmironpatriots.github.io

npm install
npm run dev
```

## Commands

```bash
npm run dev      # Start local development server
npm run build    # Build the website
npm run preview  # Preview production build
```

## Project Structure

```
src/
├── assets/
├── components/
├── layouts/
├── pages/
└── styles/

docs/
```

## Contributing

Create a branch for your work:

```bash
git checkout -b yourname/task-name
```

Before opening a pull request:

```bash
npm run build
```

Please avoid pushing unfinished work directly to `main`.
